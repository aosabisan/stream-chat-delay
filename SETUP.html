Kick Delayed Chat

An on-stream chat box for Kick (plus Twitch and YouTube through Streamer.bot) that holds each message for a few seconds, so anything AutoMod or your mods delete never reaches your stream.

1Find your chatroom

Kick didn't let this page look it up automatically. That's normal. Do this instead:

  1. Click Open Kick lookup page. A new tab opens full of text.
  2. Press Ctrl+A then Ctrl+C in that tab to copy everything.
  3. Come back here and paste it in the box below with Ctrl+V.

+Twitch & YouTube chat (optional, needs Streamer.bot)

If you use Streamer.bot and have it connected to Twitch and/or YouTube, those chats can show in the same box. They show right away (no delay needed), and anything deleted or anyone banned there is removed from the box too. Skip this if you only stream on Kick.

  1. In Streamer.bot, open Servers/Clients → WebSocket Server.
  2. Tick Auto Start, then click Start Server. Leave Address 127.0.0.1, Port 8080, Endpoint /.
  3. Keep Streamer.bot open while you stream.

2Choose your settings

A longer delay catches more slow AutoMod deletions, but Kick chat on screen runs further behind. Twitch and YouTube messages show right away, because those platforms already hold back flagged messages before anyone sees them.

Preview with fake chat. Every 4th message is a Kick message "deleted by AutoMod" and should never appear. The coloured dot shows the platform: green Kick, purple Twitch, red YouTube.

3Add it to OBS

Finish step 1 first (or tick "I don't stream on Kick").

Your OBS link:

  1. In OBS, click + under Sources and choose Browser. Name it anything.
  2. Make sure Local file is unticked.
  3. Click in the URL box, delete what's there, and paste with Ctrl+V.
  4. Set Width to 450 and Height to 700 (adjust to fit your layout), then click OK.
  5. Type a message in your chat. It should appear a few seconds later.

Don't move or rename this folder after setup. The link points to where it is right now. If you move it, open this page again and copy the new link.
